React Registration Form
A modern, responsive registration form built with React.js featuring comprehensive form validation and a beautiful UI.

📋 Features
Modern UI Design - Clean and professional interface with gradient background

Responsive Layout - Works perfectly on desktop, tablet, and mobile devices

Form Validation - Comprehensive client-side validation using HTML5 and JavaScript

Real-time Feedback - Instant validation messages for better user experience

Password Strength Meter - Visual indicator for password requirements

File Upload Support - Resume upload functionality

Accessibility - Proper ARIA labels and semantic HTML

🛠️ Technologies Used
React.js - Frontend framework

CSS3 - Styling with modern features

HTML5 - Semantic markup and form validation

JavaScript ES6+ - Modern JavaScript features

📝 Form Fields
Required Fields:
Full Name

Email Address

Contact Number (11 digits)

Gender Selection

Resume Upload

Password (with strength requirements)

Password Confirmation

Optional Fields:
Best Subject Selection

About Yourself

🎯 Password Requirements
Minimum 8 characters long

Must start with an alphabet

Must contain at least one special character (!@#$%^&*)

Real-time password strength indicator

Password confirmation matching
